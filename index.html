Practice — Font Loading & Fallbacks

A type system that still works when the good font doesn't load

This page pairs a licensed display serif with a licensed body sans, backed by system-font fallback stacks. Every size below is a token, not a one-off value, so the whole page can be re-tuned from one place.

Long-form

Reading a full paragraph

Font loading strategy affects more than which glyphs appear on screen — it changes line breaks, paragraph height, and how quickly a reader can scan a page. A fallback stack should be chosen with metric compatibility in mind: similar x-height, similar average character width, similar cap height. Two stacks that look nothing alike but happen to share those three measurements will reflow a paragraph almost identically, which is the real goal of this exercise — not matching the fallback's style, but matching its shape.

When that match is close, blocking the web font barely disturbs the layout. When it's loose, headlines wrap onto an extra line, buttons that fit one word now fit none, and the vertical rhythm of the page drifts as every element reflows against a slightly taller or shorter fallback line.
